# 🔄 GradeDeserializer — восстановление оценок из бэкапа

## 📋 Задача
Восстановить исходные "сырые" данные об учениках из красиво отформатированных строк — сделать преобразование, обратное задаче форматирования оценок. На входе теперь не одна строка с данными, а массив уже готовых для вывода фраз, которые нужно собрать обратно в единую запись через `;` и `,`.

---

## ⚙️ Функциональность
- `serializeGrades(String[] grades)` — собирает массив читаемых строк обратно в одну запись
- `gradeStringToInt(String grade)` — превращает словесную оценку обратно в число-строку

---

## 🧠 Теория

### Входные данные — массив готовых фраз
```java
String[] arrayMain = {
    "Вероника Чехова физика — Безупречно",
    "Анна Строкова математика — Потрясающе"
};
```
Раньше мы шли от "сырых" данных к красивому тексту, теперь — наоборот: от готовой фразы нужно вытащить обратно четыре поля (имя, фамилию, предмет, оценку).

### Удаление тире перед разбором
```java
String strWithoutDash = str.replace("— ", "");
```
Тире с пробелом мешает разбить строку по пробелам как по единому разделителю — его убирают заранее, а не оставляют как отдельный элемент, который потом пришлось бы отфильтровывать.

### Split по пробелу вместо `,` и `;`
```java
String[] arr = strWithoutDash.split(" ");
```
Так как во входной строке разделитель — пробел, а не запятая, `split(" ")` даёт массив из четырёх элементов: `[имя, фамилия, предмет, оценка]`. Индексы полей в точности совпадают с тем порядком, который нужен на выходе.

### Приведение регистра в обратную сторону
```java
arr[0] = arr[0].toLowerCase();
arr[1] = arr[1].toLowerCase();
```
В прошлой задаче имя и фамилию поднимали до заглавной буквы — теперь, наоборот, опускаем обратно в нижний регистр, поскольку исходный формат хранения ожидает данные именно в таком виде.

### Обратное преобразование оценки
```java
private static String gradeStringToInt(String grade) {
    switch (grade) {
        case "Безупречно": return "5";
        case "Потрясающе": return "4";
        ...
    }
}
```
Это зеркальное отражение `gradeToString` из прошлой задачи: там число превращалось в слово, здесь слово превращается обратно в число-строку через тот же принцип `switch`.

### Сборка через StringBuilder
```java
StringBuilder builder = new StringBuilder();
for (String str : grades) {
    ...
    builder.append(String.join(",", arr)).append(";");
}
```
Каждая запись сначала собирается через `String.join(",", arr)` в формат `имя,фамилия,предмет,оценка`, а затем добавляется в общий `StringBuilder` с разделителем `;` — так восстанавливается исходная "плоская" строка бэкапа.

---

## 🛠 Что использовал
- `String.replace()` для удаления тире перед разбором строки
- `String.split(" ")` для разбора фразы на четыре поля по пробелу
- `String.toLowerCase()` для возврата имени и фамилии к исходному регистру
- `switch` для обратного перевода словесной оценки в число
- `StringBuilder` + `String.join(",", arr)` для пошаговой сборки итоговой строки

---

## 💡 Вывод
Задача демонстрирует, что сериализация и десериализация — зеркальные операции: там, где раньше данные "разбирали" и "украшали", теперь их "разукрашивание" снимают и возвращают в исходный компактный формат. Такой парный подход (прямое/обратное преобразование) типичен для реальных систем бэкапов и обмена данными.
