# 🎓 GradeBeautifier — форматированный вывод школьных оценок

## 📋 Задача
Реализовать программу, которая принимает на вход одну строку с данными об учениках (имя, фамилия, предмет, оценка) и выводит их построчно в читаемом, "человеческом" формате — с заглавными буквами, словесными оценками и красивым разделителем.

---

## ⚙️ Функциональность
- `gradeBeautifier(String grades)` — разбирает строку и печатает результат построчно
- `capitalize(String str)` — приводит имя/фамилию к формату с заглавной буквы
- `gradeToString(String grade)` — превращает числовую оценку (1–5) в словесную характеристику

---

## 🧠 Теория

### Входные данные — одна строка, а не массив объектов
```java
String grades = "вероника,чехова,ФИЗИКА,5;анна,строкова,МАТЕМАТИКА,4";
```
Все ученики закодированы в одну строку. Чтобы с ними работать, её нужно разобрать в два этапа: сначала на отдельные записи, потом каждую запись — на поля.

### Двухуровневый split
```java
String[] array = grades.split(";");

for (String str : array) {
    String[] secondArray = str.split(",");
    ...
}
```
Первый `split(";")` разбивает строку на отдельных учеников. Внутри цикла второй `split(",")` разбирает запись конкретного ученика на четыре поля: имя, фамилию, предмет, оценку. Это классический паттерн разбора "плоской" строки с вложенной структурой.

### Приведение регистра
```java
String name = capitalize(secondArray[0]);
String discipline = secondArray[2].toLowerCase();
```
Имя и фамилия приходят с маленькой буквы — их нужно "поднять" через `capitalize`, который берёт первую букву, переводит в верхний регистр и склеивает с остальной частью строки. Предмет, наоборот, приходит КАПСОМ — его приводим к нижнему регистру через `toLowerCase()`.

### Перевод оценки в текст
```java
private String gradeToString(String grade) {
    switch (grade) {
        case "5": return "Безупречно";
        case "4": return "Потрясающе";
        ...
    }
}
```
Оценка хранится как строка ("5", "4"...), а не число — потому что после `split` все поля всегда строки. `switch` сопоставляет каждой оценке словесный эквивалент.

### Сборка итоговой строки
```java
System.out.println(String.join(" ", name, surname, discipline, dash, grade));
```
`String.join` склеивает все части через пробел, включая заранее подготовленное тире `—`. Это чище, чем конкатенация через `+`.

---

## 🛠 Что использовал
- Метод `String.split()` для разбора строки на двух уровнях (по `;` и по `,`)
- Собственный метод `capitalize` для приведения регистра имени и фамилии
- `switch` для преобразования числовой оценки в текстовую
- `String.join()` для сборки итоговой строки вывода
- Символ длинного тире `—` (не дефис `-`) как разделитель

---

## 💡 Вывод
Задача показывает типичный паттерн парсинга "плоских" данных из одной строки: разбить на записи → разбить запись на поля → нормализовать каждое поле → собрать в читаемый вид. Тот же подход используется при разборе CSV, логов и любых текстовых форматов с разделителями.
