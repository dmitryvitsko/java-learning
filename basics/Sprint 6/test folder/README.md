# 📐 HandMadeArrayList — реализация ArrayList своими руками

## 📋 Задача
Написать собственную упрощённую реализацию ArrayList<T> чтобы
понять как эта коллекция работает изнутри - как хранятся
элементы, что происходит при добавлении, как растёт массив.

---

## ⚙️ Функциональность
- `add(T newElement)` - добавить элемент в конец списка
- `get(int index)` - получить элемент по индексу
- Автоматическое увеличение вместимости на 50% при заполнении

---

## 🧠 Теория

### Под капотом ArrayList — обычный массив
```java
private Object[] elements;
private int size = 0;
```
Все эти годы работы со стандартным ArrayList - на самом деле
внутри просто хранится обычный массив Object[]. size - отдельная
переменная которая отслеживает сколько реальных элементов
сейчас лежит в массиве (не путать с длиной самого массива -
она обычно больше чем size, с запасом).

### Проверка перед добавлением
```java
public void add(T newElement) {
    if (size == elements.length) {
        grow();
    }
    elements[size] = newElement;
    size++;
}
```
Перед каждым добавлением проверяем - остались ли свободные
ячейки в массиве. Если массив заполнен полностью (size ==
elements.length) - сначала увеличиваем его через grow(),
и только потом кладём новый элемент.

### Рост массива на 50%
```java
private void grow() {
    Object[] newArray = new Object[elements.length + elements.length / 2];
    for (int i = 0; i < elements.length; i++) {
        newArray[i] = this.elements[i];
    }
    this.elements = newArray;
}
```
Массив в Java имеет фиксированный размер - увеличить существующий
массив нельзя. Поэтому создаётся НОВЫЙ массив большего размера,
все элементы копируются туда, и старый массив заменяется новым.

Это именно то что происходило раньше в задаче про динамический
список покупок (ShoppingDynamic) - только там рост был x2,
а здесь x1.5 (+50%). Реальный ArrayList в Java тоже растёт
именно на 50%, а не удваивается.

### Приведение типа при чтении
```java
public T get(int index) {
    return (T) this.elements[index];
}
```
Массив хранится как Object[] - поэтому при получении элемента
нужно явно привести его обратно к типу T. Это происходит "под
капотом" незаметно для пользователя стандартного ArrayList.

---

## 🛠 Что использовал
- Обобщённый класс `HandMadeArrayList<T>`
- Массив `Object[]` как внутреннее хранилище (единый способ
  хранить любые типы данных до приведения)
- Стратегия роста массива при заполнении (+50% вместимости)
- Копирование элементов в новый массив через цикл
- Явное приведение типа `(T)` при чтении элемента

---

## 💡 Вывод
За удобным API ArrayList (add, get, remove) стоит простая
идея - массив который сам себя пересоздаёт когда становится
тесно. Понимание этого механизма объясняет почему добавление
элемента иногда происходит мгновенно, а иногда чуть медленнее -
это момент когда массив пересоздаётся и копируется целиком.
